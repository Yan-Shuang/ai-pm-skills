# 可复制示例

以下为预先编写、AI辅助生成的虚构产品教学示例，不是对真实产品的研究或实测。

## 1. 静态状态能证明什么

输入：

```text
$evidence-based-teardown
只拆解“邀请队友”流程，不浏览。
E1（用户提供截图文字转录；版本/日期/套餐未知）：邀请弹窗上部有邮箱输入框，底部有“发送邀请”，输入为空时按钮呈灰色。
E2（用户提供官方帮助摘录，“邀请”第2段；版本/日期未知）：受邀人会收到邀请邮件，接受后加入工作区。
没有实际点击记录。
```

输出示范：

```text
范围：邀请队友；未操作产品，仅依据转录和摘录。
台账：E1截图文字转录→弹窗上部/底部，日期、版本、套餐未知；E2用户提供官方帮助摘录→邀请第2段，日期、版本未知。
流程：输入邮箱[入口见E1]→发送[入口见E1，实际响应未知]→邮件→接受加入[文档陈述E2，未实测]。
C1 [观察] 空输入状态中按钮呈灰色→E1底部；不能仅凭颜色断定不可点击。
C2 [来源事实] 文档描述邮件邀请及接受加入→E2第2段；不代表已测到邮件到达。
C3 [推断] 灰色可能表达未满足输入条件→E1；也可能只是视觉样式。
C4 [待核实] 邮箱校验、重复邀请、发送失败状态缺少证据。
H1 [改进假设] 若新用户不知道灰色原因，在该状态解释邮箱要求可能提升首次成功发送比例；小范围比较有/无解释的完成率。若完成率无改善或干扰输入，则反驳假设。当前没有基线。
最小补证：合法测试账号下记录空输入点击与有效邮箱提交后的状态；不要自动给真人发送邀请。
```

## 2. 来源冲突，不把日期当万能答案

输入：

```text
$evidence-based-teardown
拆解“导出PDF”。资料均为用户提供摘录。
E1（官方帮助，2026-08，免费版行）：免费版可导出PDF。
E2（官方套餐页，2026-09，免费版行）：PDF导出只对付费版开放。
E3（体验记录，2026-09-20）：测试账号为团队付费版，点击导出后得到PDF。
```

输出示范：

```text
范围：PDF导出权限与结果；没有本人实测。
台账：E1帮助免费版行；E2套餐页免费版行；E3用户体验记录第1条。E1/E2版本未知，E3团队付费版。
C1 [观察，依据用户体验记录] 团队付费账号当次导出得到PDF→E3；不外推所有账号。
C2 [待核实] 免费版是否可导出→E1与E2明确冲突；日期不同可能是政策变更，但不能仅凭晚一个月确认所有免费用户当前权限。
C3 [推断] 可能存在政策变更、套餐差异或帮助未更新→E1/E2，尚无直接验证。
流程：团队付费版点击→得到PDF[仅E3当次]；免费版入口及结果未知。
H1 [改进假设] 若免费用户无法判断权限，在入口标明适用套餐可能减少无效尝试；观察有效导出完成比例与权限咨询量。若无变化则不支持假设。
补证：核对文档适用版本，并在授权免费测试账号读取导出状态。当前证据不足以宣称这是免费版缺陷。
```

## 3. 没有证据也能交付诚实边界

输入：

```text
$evidence-based-teardown
分析竞品A的智能摘要，大家都说它很准。没有链接、截图、文档或体验记录，也不能浏览。
给出可用于下一步调查的结果。
```

输出示范：

```text
范围：智能摘要；证据台账为空。“大家都说很准”不是可定位的准确性测量。
事实/观察：当前无可核验产品材料；无法还原真实输入、结果和错误状态。
待核实：支持的输入类型、摘要输出、准确性定义、来源引用方式、失败处理。
调查骨架（非已观察流程）：准备代表性输入→取得摘要→逐项核对原文→记录遗漏/错误及引用。
H1 [改进假设] 若摘要的关键结论缺少原文定位，为需要核实内容的用户增加出处可能缩短核对时间；比较有/无出处的核对耗时和错误检出。若耗时未减少或错误增加，则反驳假设。
最小补证：1个授权样例的输入与输出、1份版本明确的官方说明。没有这些材料不能判断当前产品实现或准确率。
```
