## 最小补证与反馈校准

继续讨论替代时，优先补齐：B02 在相同 brief/S1 下的 v1 输出；v1/v2 的原始 Prompt 快照；修订后 v2 在两个 case 上的实际输出。随后沿用同一 rubric 和 issue_id，核查两个 critical 是否消失、是否新增严重问题、各维是否退化。未经该轮评测，不把建议稿当作已解决。

80% 数字无需为了修稿专门补实验，当前直接删除即可；若运营坚持保留，再请求真实测量证据，核实前保持 pending。防火主张已有明确反证，应删除，不进入“等待证实防火”的队列。
