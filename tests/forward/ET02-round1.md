# PDF 导出：局部流程拆解

## 范围与证据覆盖限制

分析单元是“用户从账号内导出PDF”，重点检查套餐资格与导出结果。材料包含两份对免费版权益表述相反的官方摘录，以及一条团队付费账号获得PDF的体验记录。

本次只依据用户提供摘录和用户体验记录，未浏览、未亲自操作。两份资料的月份不能单独确定政策生效时间或所有账号的当前行为；付费账号的成功记录也不能验证免费账号的资格。

对团队付费账号，当前记录未显示这次导出存在明确障碍。对免费账号，证据尚不足以评价导出流程是否顺畅；两份资料的冲突会妨碍分析者确认资格，但没有证据证明用户已实际看到两份资料并因此受阻。

## 最小补证／实验清单

1. 补齐两份官方摘录的标题、完整上下文及适用范围，尤其是政策生效日期、免费版定义、旧账号或特定账号例外。保留E1、E2各自定位；在确认前不删除任一表述。
2. 补一条目标免费账号在明确日期、版本和套餐下的记录：导出入口状态、点击后反馈及是否得到PDF。若政策包含旧账号例外，再针对该例外补证；单个免费账号记录仍只覆盖自身条件。
3. 若要评价输出质量，再取一个经授权且脱敏的PDF样本，对照原内容检查完整性和版式；当前无需假定质量有问题。
4. 在资格规则核实后，可做小范围说明原型实验：**针对谁／哪个步骤**＝免费用户、判断能否导出PDF时；**假设**＝清楚说明适用资格与必要例外可提高资格判断的准确性；**怎样验证**＝让目标用户阅读现有说明与统一说明原型，并回答给定账号能否导出及下一步是什么；**反驳信号**＝判断准确性未提高，或统一说明造成更多误解。此建议是改进假设，没有用户困惑或收益基线，不代为修改产品。
