# 成员列表导出验收标准

## 1. 已知条件与排除项

| 编号 | 已知条件 |
| --- | --- |
| R1 | 管理员可以导出成员列表。 |
| R2 | 其他角色不能导出成员列表。 |
| R3 | 本次不做批量操作和定时任务。 |

合理假设：无。未自行指定管理员之外的角色名称、导出格式、字段或成员范围。

## 2. 阻塞性澄清

以下问题影响完整导出结果的通过或失败判定；权限部分可以先按已知条件验收。

| 编号 | 问题 | 受阻标准 |
| --- | --- | --- |
| Q1 | 导出应包含哪些成员：全部成员、当前筛选结果，还是其他明确范围？ | AC03 的成员范围判定。 |
| Q2 | 导出应包含哪些字段？ | AC03 的导出内容判定。 |
| Q3 | 导出的格式和交付方式是什么？例如下载文件或提供可获取的导出结果；若是文件，需确认格式。 | AC03 的完成结果与可获取性判定。 |

导出失败后的状态和用户可观察结果尚未定义，AC04 保留为待确认，不自行增加重试、恢复或提示组件。

## 3. 正常及相关异常路径与验收标准

| ID | 状态 | 依据 | Given / When / Then |
| --- | --- | --- | --- |
| AC01 | 已确认 | R1 | **Given** 当前用户的角色为管理员，且正在使用成员列表功能；**When** 用户发起成员列表导出；**Then** 系统允许其执行导出操作，操作不因角色权限而被拒绝。导出结果的内容与交付按 AC03 补齐。 |
| AC02 | 已确认 | R2 | **Given** 当前用户为任一已配置的非管理员角色；**When** 用户尝试通过成员列表导出的操作入口或请求路径发起导出；**Then** 系统不执行该用户的成员列表导出，也不向其返回成员列表导出结果。对各非管理员角色分别验证。入口隐藏、禁用或拒绝提示的具体表现尚未指定。 |
| AC03 | 待确认 | R1、Q1、Q2、Q3 | **Given** 当前用户为管理员，导出成员范围、字段、格式和交付方式已确认，且本次导出成功完成；**When** 用户获取导出结果；**Then** 用户能通过已确认的交付方式取得结果，结果包含已确认范围内的成员及字段，并符合已确认的格式。Q1～Q3 未回答前，无法据此判定内容完整性或交付正确性。 |
| AC04 | 待确认 | R1；失败处理尚未决定 | **Given** 当前用户为管理员，且本次导出发生错误、未成功完成；**When** 导出进入失败状态；**Then** 待确认失败后应保留何种状态、用户能观察到什么结果，以及是否提供后续操作。此处不要求重试、恢复、自动保存或额外提示组件。 |

AC03 的前提为导出成功完成，AC04 的前提为发生错误且未成功完成，两条路径互斥。只有已确认标准可直接进入当前验收清单。

## 4. 可选建议与后续补齐

可选建议：无。不增加本次验收范围。

确认 Q1～Q3 后，可补齐完整成功路径的实际数据范围、字段和交付判定。失败路径还需决定失败后的状态与用户可观察结果；若产品需要后续处理操作，再补齐对应标准。批量操作和定时任务继续排除在本次范围之外。
