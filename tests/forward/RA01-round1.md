# 本地草稿删除验收标准

## 1. 已知条件与排除项

| 编号 | 已知条件 |
| --- | --- |
| R1 | 删除范围仅为当前选中的一条本地草稿。 |
| R2 | 点击删除后，先进行确认。 |
| R3 | 用户确认删除后，该草稿从列表消失。 |
| R4 | 用户取消删除后，该草稿保留在列表中。 |
| R5 | 无选中草稿时，删除操作不可用。 |
| R6 | 本次不包含回收站、批量删除或撤销。 |

合理假设：无。

## 2. 阻塞性澄清

无阻塞性问题，可按已知条件执行验收。

## 3. 正常及相关异常路径与验收标准

| ID | 状态 | 依据 | Given / When / Then |
| --- | --- | --- | --- |
| AC01 | 已确认 | R1、R2 | **Given** 当前选中一条本地草稿，且该草稿在列表中；**When** 用户点击删除；**Then** 系统呈现删除确认，用户作出确认或取消决定前，该草稿仍在列表中。 |
| AC02 | 已确认 | R1、R2、R3 | **Given** 针对当前选中草稿的删除确认已呈现，且用户尚未取消；**When** 用户确认删除；**Then** 该草稿从列表消失。 |
| AC03 | 已确认 | R2、R4 | **Given** 针对当前选中草稿的删除确认已呈现，且用户尚未确认；**When** 用户取消删除；**Then** 该草稿仍保留在列表中。 |
| AC04 | 已确认 | R5 | **Given** 当前没有选中草稿；**When** 用户查看或尝试使用删除操作；**Then** 删除操作不可用，无法通过该操作触发草稿删除。 |
| AC05 | 已确认 | R1、R3、R6 | **Given** 列表中有多条本地草稿，当前仅选中其中一条；**When** 用户点击删除并确认；**Then** 只有当前选中的草稿从列表消失，其余草稿仍在列表中。 |

## 4. 可选建议与后续补齐

可选建议：无。不增加本次验收范围。

本次核心行为无需补充产品决定即可验收。确认提示的具体文案与呈现方式可后续细化。
